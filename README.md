# Sliding Puzzle Android

A bright, offline sliding puzzle game for Android with number and personal-photo modes.

Development is in progress on `v0.1.0-dev1`.

Features planned for this first version:

- Configurable square puzzle sizes.
- Number and photo modes, with reusable private photo history.
- Android photo picker and image sharing into the game.
- Swipe movement, optional tap movement, and a completion celebration.

Photo processing and storage stay on the device.
